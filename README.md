# Badaya Field 사용 설명서 (직원용)

Badaya Travel 현장 업무용 앱입니다. 투어 고객의 **옵션 주문서**를 쓰고, 고객에게 **받은 돈**과 현장에서 **쓴 돈**을 기록하고, 투어가 끝나면 **정산**까지 휴대폰 하나로 합니다.

한 사람이 입력하면 사무실과 다른 직원 휴대폰에도 **바로** 반영됩니다. 그래서 따로 엑셀을 주고받거나 사진을 찍어 보낼 필요가 없습니다.

- 앱 주소: **https://jihkim1210-dev.github.io/badayaTravel.github.io/**

## 1. 처음 시작하기

### 1-1. 계정 받기

- 이 앱에는 **회원가입 버튼이 없습니다.** 사무실(관리자)이 계정을 만들어 **이메일과 비밀번호**를 알려 드립니다.
- 처음 받은 비밀번호는 다른 사람과 공유하지 마세요. 한 계정을 여러 사람이 쓰면 누가 수금했는지 기록이 섞입니다.

### 1-2. 휴대폰에 설치하기

앱스토어에서 받는 앱이 아니라, 주소를 열어 **홈 화면에 추가**해서 씁니다. 한 번 추가하면 일반 앱처럼 주황색 **B** 아이콘을 눌러 전체 화면으로 열립니다.

| 휴대폰 | 방법 |
|---|---|
| 아이폰 | **Safari**로 주소 열기 → 아래쪽 공유 버튼(□↑) → **홈 화면에 추가** → 오른쪽 위 **추가** |
| 안드로이드 | **Chrome**으로 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가** |

- 아이폰은 반드시 **Safari**로 열어야 홈 화면에 추가할 수 있습니다. 카카오톡에서 링크를 누르면 카카오톡 안의 브라우저로 열리는데, 이때는 오른쪽 아래(또는 위) 메뉴에서 **다른 브라우저로 열기 → Safari**를 고르세요.
- 안드로이드에서 앱 설치 안내가 아래쪽에 자동으로 뜨면 **설치**를 눌러도 됩니다.
- 앱 안의 **설정** 탭에도 같은 설치 방법이 적혀 있습니다.

### 1-3. 로그인

1. 홈 화면의 아이콘을 눌러 앱을 엽니다.
2. 받은 **이메일**과 **비밀번호**를 넣고 **로그인**을 누릅니다.
3. 투어 목록이 보이면 끝입니다.

- 한 번 로그인하면 **로그아웃하기 전까지 유지**됩니다. 매번 로그인할 필요가 없습니다.
- ‘로그인하지 못했습니다’가 나오면 이메일 오타(특히 대소문자·띄어쓰기)를 확인하세요. 그래도 안 되면 관리자에게 말해 주세요.
- 비밀번호는 **설정 → 비밀번호 바꾸기**에서 바꿀 수 있습니다.
- 비밀번호를 잊었으면 관리자에게 요청하세요. 관리자가 새 비밀번호로 다시 정해 줍니다. 앱에는 비밀번호 찾기 기능이 없습니다.
- 휴대폰을 바꾸거나 다른 사람에게 넘길 때는 **설정 → 로그아웃**을 먼저 누르세요.

### 1-4. 화면 맨 위 상태 표시 읽기

오른쪽 위의 작은 표시는 **내가 입력한 내용이 서버에 잘 들어가고 있는지** 알려줍니다. 수금을 기록한 뒤에는 습관적으로 한 번씩 보세요.

| 표시 | 뜻 | 할 일 |
|---|---|---|
| 🟢 **실시간 연결** | 정상. 입력하는 즉시 모든 직원 화면에 반영 | 없음 |
| 🟡 **연결 중** | 서버와 다시 연결하는 중 | 잠시 기다리기 |
| 🟡 **전송 중 N건** | 입력한 N건을 서버로 보내는 중 | 잠시 기다리기 |
| 🔴 **오프라인 · 대기 N건** | 인터넷이 끊김. 입력한 N건은 휴대폰에 안전하게 보관 중 | 계속 입력해도 됩니다. 인터넷이 다시 연결되면 자동으로 전송됩니다. |
| ⚪ **로그인 필요** | 로그인 전 | 로그인하기 |

> ⚠️ **대기 건수가 0이 될 때까지** 앱을 지우거나, 로그아웃하거나, 브라우저 기록·데이터를 삭제하지 마세요. 아직 서버로 가지 않은 기록이 사라집니다.

## 2. 화면 구성

화면 아래쪽에 탭이 3개 있습니다.

| 탭 | 내용 |
|---|---|
| **투어** | 투어 목록, 오늘 수금 현황, 최근 기록. 앱을 열면 처음 보이는 화면 |
| **상품** | 지역별 옵션 상품과 가격. 모두 볼 수 있고, 수정은 관리자만 |
| **설정** | 내 이름·권한, 앱 설치 방법, 서버 연결 상태, 로그아웃 |

### 2-1. 투어 목록 (첫 화면)

- **오늘 수금**: 오늘 모든 투어에서 기록된 수금 합계 (통화별)
- **진행중 투어 미수금**: 진행중인 투어에서 아직 받지 못한 금액 합계
- **진행중 / 정산 제출 / 완료 / 전체**: 투어 상태별로 걸러 보기
- **투어 카드**: BDY 번호, 지역, 기간 코드, 출발일, 가이드, 인원, 판매액, 수금액, 수금률 막대, 미수금
- **최근 기록**: 모든 투어에서 방금 입력된 수금·지출 8건. 누르면 그 투어로 이동합니다.

### 2-2. 투어 화면

투어 카드를 누르면 들어가는 화면입니다. 위쪽에 탭 5개가 있습니다.

| 탭 | 하는 일 | 기존 엑셀과 비교 |
|---|---|---|
| **주문서** | 고객 명단과 고객별 옵션 선택 | CC 시트 위쪽 |
| **수금** | 고객에게 받은 돈 기록, 미수 고객 확인 | 수금 메모 |
| **지출** | 현장에서 쓴 돈, 계좌이체·환전 기록 | 정산서의 지출 칸 |
| **정산** | A~F 계산, 보유 현금 세기, 편차 확인, 제출 | PROJECT SETTLEMENT |
| **요약** | 상품별 인원·금액 합계, 엑셀 내려받기 | CC 시트 아래쪽 합계 |

## 3. 투어 하루 흐름 (요약)

처음이라면 이 순서만 기억하세요. 자세한 방법은 4장에 있습니다.

**출발 전 (사무실 또는 가이드)**
1. **+ 새 투어**로 투어를 만든다 (BDY 번호, 지역, 출발일).
2. 주문서 탭에서 **명단 붙여넣기**로 고객을 한 번에 넣는다.
3. 한국에서 미리 결제한 옵션은 **선결제**, 홈쇼핑 포함 옵션은 **홈쇼핑**으로 표시해 둔다.
4. 정산 탭의 **A 회사에서 받은 돈**에 받아 간 현금을 적는다.

**투어 중 (가이드)**
5. 고객이 옵션을 신청하면 주문서에서 **현금**으로 표시한다.
6. 돈을 받으면 **그 자리에서** 수금을 기록한다.
7. 돈을 쓰면 **그 자리에서** 지출을 기록한다.
8. 저녁에 수금 탭의 **미수 고객**을 확인한다.

**투어 끝 (가이드 → 사무실)**
9. 정산 탭에서 **보유 현금**을 권종별로 세어 넣고 **편차**가 0인지 본다.
10. 맞지 않으면 사유를 **비고**에 적고 **정산 제출**을 누른다.
11. 사무실에서 확인 후 **정산 완료**로 잠근다.

## 4. 단계별 사용법

### 4-1. 투어 만들기

투어 목록에서 **+ 새 투어**를 누르고 입력합니다.

| 칸 | 입력 형식 | 예 |
|---|---|---|
| BDY 번호 | **숫자만**. 같은 번호의 투어는 하나만 만들 수 있음 | `4229` |
| 지역 | **두바이** (AED, 팁만 USD) / **이집트** (EUR, Cruise Tips만 USD) | 이집트 |
| 투어 기간 코드 | 목록에서 고르거나 직접 입력 | `EK3N6D`, `KE4N6Dsig` |
| 출발일 | 날짜 선택 | 2026-10-05 |
| 가이드 / 인솔자 | 이름 (기본값은 내 이름) | 김가이드 |
| Tour Expense 요금 (이집트만) | €90 또는 €100 중 선택 | €100 |

- 지역을 고르면 그 지역의 상품만 주문서에 나옵니다. **지역을 잘못 고르면 상품이 다르게 나오니** 처음에 꼭 확인하세요.
- 투어 정보는 투어 화면 오른쪽 위 **✎** 버튼으로 언제든 고칠 수 있습니다.
- 이집트 투어에서 Tour Expense 요금을 나중에 바꾸면, 이미 입력한 고객들의 Tour Expense 금액도 함께 바뀝니다.
- 투어는 **만든 사람(담당 직원)과 관리자만** 볼 수 있습니다. 다른 직원의 투어는 목록에 나오지 않습니다.
- 같은 BDY 번호는 두 번 만들 수 없습니다. 이미 있는 번호라고 나오면 다른 직원이 등록했을 수 있으니 관리자에게 확인하세요.
- 관리자는 투어 정보 수정(✎)에서 **담당 직원**을 바꿀 수 있습니다.

### 4-2. 고객 넣기

투어 화면 → **주문서** 탭.

**여러 명 한 번에 넣기: 명단 붙여넣기 (권장)**

엑셀이나 구글 시트의 고객 명단에서 아래 순서의 **4개 열**을 드래그해서 복사한 뒤, 앱의 입력칸에 붙여넣고 **추가**를 누릅니다.

| A열 | B열 | C열 | D열 |
|---|---|---|---|
| 그룹 번호 | 한글 이름 | 영문 이름 | 호칭 (Mr/Ms) |

붙여넣으면 이런 모양이 됩니다.

```
1	홍길동	HONG/GILDONG	Mr
	김영희	KIM/YOUNGHEE	Ms
2	이철수	LEE/CHULSOO	Mr
```

- 한 줄에 한 명입니다. 엑셀에서 복사하면 칸 사이가 자동으로 탭으로 들어갑니다. 휴대폰에서 직접 입력할 때는 쉼표(`,`)로 나눠도 됩니다. 예: `1, 홍길동, HONG/GILDONG, Mr`
- **그룹 칸이 비어 있으면 바로 윗줄의 그룹을 따릅니다.** 엑셀에서 그룹 번호를 첫 사람에게만 적었거나 셀을 병합한 경우에도 그대로 복사하면 됩니다. 위 예에서 김영희는 1그룹입니다.
- 그룹 열 없이 `한글, 영문, 호칭` 3개 열만 붙여넣어도 됩니다. 이때는 모두 1그룹이 됩니다.
- 호칭은 `Mr`, `Ms`만 알아듣습니다(대소문자 상관없음). 그 외에는 비워 둡니다.
- **제목 줄(그룹, 이름…)은 복사하지 마세요.** 제목 줄도 고객으로 들어갑니다. 잘못 들어간 사람은 이름을 눌러 **삭제**하면 됩니다.
- 같은 명단을 두 번 붙여넣으면 두 번 들어갑니다. 붙여넣기 전에 이미 들어간 고객이 있는지 확인하세요.

**한 명씩 넣기: + 고객 추가**

| 칸 | 형식 | 예 |
|---|---|---|
| 그룹 | 숫자. 비워 두면 0(그룹 없음) | `1` |
| 이름 (한글) | 자유 | 홍길동 |
| 이름 (영문, 여권) | 여권 표기 그대로. 자동으로 대문자로 바뀜 | `HONG/GILDONG` |
| 호칭 | Mr / Ms | Mr |
| 특이사항 | 자유. 카드 보기에서 노란 글씨로 보임 | 홈쇼핑 고객, 보상 사유, 채식 |

- 한글·영문 이름 중 하나는 꼭 입력해야 합니다.
- **추가 후 계속**을 누르면 창이 닫히지 않고 다음 고객을 바로 입력할 수 있습니다(그룹 번호는 유지).

**고객 수정·삭제**
- 고객 이름을 누르면 수정 창이 열립니다.
- **삭제**를 누르면 그 고객의 주문까지 같이 지워집니다.
- 수금 기록이 있는 고객은 삭제되지 않습니다. 수금 탭에서 그 고객의 수금 기록을 먼저 지운 뒤 삭제하세요.

### 4-3. 옵션 주문 받기

주문서 탭 위쪽의 **누르면** 줄에서 먼저 **상태**를 고르고, 고객 줄에서 **상품 칸**을 누릅니다.

주문서는 처음에 엑셀처럼 생긴 **표**로 열립니다. 한 줄이 고객 한 명, 한 열이 상품 하나입니다. 오른쪽 위 **표 / 카드** 버튼으로 고객별 카드 보기로 바꿀 수 있고, 고른 보기는 다음에도 그대로 유지됩니다.

| 상태 | 뜻 | 받을 돈에 포함 | 버튼 색 | 엑셀 CC 시트 표기 |
|---|---|---|---|---|
| **현금** | 현장에서 고객에게 돈을 받을 옵션 | **포함** | 초록 | 1 |
| **선결제** | 한국에서 미리 결제한 옵션 | 제외 | 청록 | 0 |
| **홈쇼핑** | 홈쇼핑 상품에 포함된 옵션 | 제외 | 보라 | 0 |
| **보상** | 회사가 보상으로 제공하는 옵션 | 제외 | 금색 | 0 |

**예시**: 홍길동 고객이 Burj Khalifa를 현장에서 신청했고, Desert Safari는 한국에서 미리 결제했다면
1. **현금**을 고른 상태에서 홍길동 줄의 **Burj Khalifa** 칸을 누릅니다 → 초록색 ●
2. **선결제**를 고르고 홍길동 줄의 **Desert Safari** 칸을 누릅니다 → 청록색 P
3. 홍길동의 받을 돈은 Burj Khalifa 금액만 잡힙니다.

**알아 두면 좋은 것**
- **같은 상태에서 한 번 더 누르면 취소**됩니다. 실수로 눌렀으면 다시 누르세요.
- 이미 ‘현금’인 상품을 ‘선결제’ 상태에서 누르면 선결제로 바뀝니다.
- 상품 가격은 **누른 순간의 가격**으로 저장됩니다. 나중에 사무실에서 가격을 바꿔도 이미 입력한 주문은 그대로입니다.
- 표에서 ● = 현금, P = 선결제, H = 홈쇼핑, C = 보상입니다. 표가 화면보다 넓으면 옆으로 밀어서 보세요. 고객 이름 칸은 고정되어 있습니다.
- **카드** 보기는 고객 한 명씩 상품 이름이 크게 보여서 휴대폰에서 한 사람씩 확인할 때 편합니다. 카드 보기에서 **선택한 상품만**을 켜면 고른 상품만 보여서 화면이 짧아지고, 상품을 더 고를 때는 **+ 상품 선택**을 누르세요.
- 화면 아래 검은 막대는 이 투어의 **현금 판매 합계**입니다.
- 결합상품(예: 피라미드 내부 탐험 + 문명박물관, 덴데라 + 사막 사파리)은 요약의 ‘총 옵션 수’에서 2개로 계산됩니다.

#### 주문하기

주문서 탭의 고객 표 위에 주문 상자가 있습니다.

1. 고객별 옵션을 다 표시했으면 **주문하기**를 누릅니다.
2. 상품별 수량을 확인하고, 필요하면 남길 말을 적은 뒤 **주문하기**를 누릅니다. → **1차 주문**. 주문서 엑셀 파일이 주문 담당자에게 이메일로 갑니다.
3. 그 뒤에 신청이 늘거나 취소되면 표에서 그대로 고칩니다. 상자가 주황색으로 바뀌고 **주문 후 바뀐 상품**이 표시됩니다.
4. **바뀐 내용으로 다시 주문하기**를 누르면 바뀐 상품이 색으로 표시된 확인 창이 뜨고, 보내면 **2차 주문**이 됩니다.

- **주문서 다운로드**: 지금 표 내용으로 주문서 엑셀을 받습니다. 시트는 ‘주문서’(상품별 수량·금액, 통화별 합계 금액, 현금/선결제/홈쇼핑/보상 인원·티켓 수, 2차부터는 이전 주문 대비 변경)와 ‘고객 명단’(상품별 고객 이름) 2개입니다.
- 파일 이름 끝에 **주문 날짜와 시간**이 붙습니다. 예: `BDY4229_DUBAI_주문서_2차_2026-10-11_14-30.xlsx`
- 이메일이 가지 않았으면 상자에 **이메일 다시 보내기** 버튼이 나옵니다. 인터넷이 연결된 곳에서 눌러 주세요.
- **주문 기록**을 펼치면 1차, 2차 … 보낸 주문서를 차수별로 다시 받을 수 있고, 관리자가 확인했는지도 보입니다.
- 주문 담당자는 받은 이메일의 **주문 확인** 버튼을 누르면 됩니다. 관리자는 앱 홈 화면 **받은 주문서**에서 **확인**을 눌러도 됩니다. 확인하면 직원 화면에 **관리자 확인**으로 표시됩니다.

### 4-4. 돈 받기 (수금)

고객이 돈을 내면 **바로** 기록합니다. 나중에 몰아서 적으면 누가 얼마 냈는지 헷갈립니다.

**가장 빠른 방법**
1. 주문서 탭에서 고객 줄 끝(카드 보기에서는 카드 아래)의 주황색 미수 금액 버튼을 누릅니다.
2. 그 고객의 남은 금액이 자동으로 채워져 있습니다.
3. 전액을 받았으면 **수금 저장**만 누르면 끝입니다. 일부만 받았으면 금액을 받은 만큼으로 고친 뒤 저장합니다.

수금 탭의 **+ 수금 기록**으로도 입력할 수 있습니다.

| 칸 | 형식 |
|---|---|
| 고객 | 고객 선택. 특정 고객 몫이 아닌 돈은 ‘공통’ |
| 통화 | EUR / USD / KRW / AED / EGP |
| 금액 | 숫자만 (쉼표·기호 없이). 소수점 둘째 자리까지 |
| 방법 | 현금 / 카드 / 계좌이체 |
| 메모 | 자유 (예: 나머지는 내일, 50유로 지폐로 받음) |

- **통화는 서로 환산하지 않습니다.** 한 고객이 두 통화로 내야 하면 **통화별로 따로** 두 번 기록합니다.
  - 두바이: 옵션 **AED** + 팁 **USD**
  - 이집트: Tour Expense·옵션 **EUR** + Cruise Tips **USD**
- 고객이 AED 대신 다른 통화로 냈다면, 실제로 받은 통화와 금액 그대로 적고 메모에 사정을 남겨 주세요(예: AED 330 대신 USD 90 받음). 정산 때 사무실에서 판단합니다.
- 카드나 계좌이체로 받았으면 **방법**을 꼭 바꾸세요. 정산에서 손에 있는 현금과 구분하기 위해서입니다.
- 잘못 입력한 수금은 수금 탭 목록에서 **×** 를 눌러 지우고 다시 입력합니다.
- 다 받은 고객은 카드 보기에서 초록색 **완납**으로 표시됩니다.

**수금 탭에서 보이는 것**
- 통화별 **판매(현금) / 수금 / 남은 금액**. 남은 금액이 마이너스(빨간색)면 받을 돈보다 많이 받았다는 뜻입니다. 입력 실수가 없는지 확인하세요.
- **미수 고객** 목록과 바로 수금 버튼
- **수금 내역**: 언제, 누가, 어떤 방법으로 받았는지

### 4-5. 돈 쓰기 (지출)

**지출** 탭 → **+ 지출 기록**. 돈을 쓰는 즉시 기록하세요.

| 칸 | 형식 | 예 |
|---|---|---|
| 구분 | **투어 지출** 또는 **계좌이체·환전** | 투어 지출 |
| 장소 | 두바이 / 이집트 / 사무실 | 두바이 |
| 항목 | 목록에서 고르거나 직접 입력 | 팁, 커미션, 보상, 가이드 대납, 크루즈팁, 입장료, 식사, 교통, 기타 |
| 통화 · 금액 | 수금과 같은 형식 | AED 40 |
| 메모 | 자유 | 사파리 드라이버 팁 |

- 손에 있던 현금을 회사 계좌로 보냈거나 다른 통화로 환전해서 그 통화가 줄었으면 **계좌이체·환전**으로 기록합니다(정산서의 ‘계좌이체 및 교환’ 칸).
- 환전으로 **늘어난** 통화는 정산 탭의 **A 회사에서 받은 돈**에 더해서 적어 주세요.
  - 예: USD 100을 AED 365로 환전 → 지출에 `계좌이체·환전 USD 100`, 정산 A의 AED에 `+365`
- 영수증이 있으면 메모에 영수증 번호나 가게 이름을 적어 두면 정산 때 편합니다.

### 4-6. 정산하기

투어가 끝나면 **정산** 탭에서 합니다. 기존 PROJECT SETTLEMENT 엑셀과 같은 계산입니다.

| 줄 | 뜻 | 입력 |
|---|---|---|
| **A** 회사에서 받은 돈 | 출발 때 회사에서 받아 간 현금 | 통화별로 **직접 입력** |
| **B** 판매 (현금 주문) | 주문서에서 ‘현금’으로 표시한 옵션 합계 | 자동 |
| **C** 지출·계좌이체 | 지출 탭 합계 | 자동 |
| **D** 카드·계좌이체 수금 | 고객이 카드·계좌이체로 낸 돈. 손에 있는 현금이 아니므로 뺌 | 자동 |
| **F** 있어야 할 돈 | A + B − C − D | 자동 |
| **E** 보유 현금 | 지금 실제로 가지고 있는 현금 | **보유 현금 세기**에서 권종별 장수 입력 |
| **편차** | E − F | 자동 |

**보유 현금 세는 법**
1. 가진 현금을 통화별로 나눕니다.
2. 지폐를 권종별로 세어 **장수**를 적습니다(금액이 아니라 장 수). 예: 100달러 9장이면 100 칸에 `9`.
3. 동전이나 권종 칸에 없는 돈은 **동전·기타 금액**에 **금액**으로 적습니다.
4. 표에 없는 통화(예: 이집트 파운드)를 가지고 있으면 **다른 통화 추가**에서 고른 뒤 셉니다.
5. 숫자는 입력하고 다른 곳을 누르는 순간 저장됩니다.

**편차 읽는 법**

| 편차 | 색 | 뜻 |
|---|---|---|
| 0 | 초록 | 정확히 맞음 |
| 마이너스 | 빨강 | 돈이 부족함 |
| 플러스 | 주황 | 돈이 남음 |

- 아직 못 받은 미수금이 있으면 그만큼 마이너스로 나옵니다. 수금 탭에서 미수 고객부터 확인하세요.
- 편차가 생기면 **비고**에 사유를 적습니다(예: 360 비는 돈, 20유로 추가 납부 필요).

**정산 제출과 확인**
1. 가이드가 확인을 마치면 **정산 제출**을 누릅니다. 투어 상태가 ‘정산 제출’로 바뀝니다.
2. 사무실에서 **재무팀 확인**, **대표 확인**을 누릅니다(관리자만). 누가 언제 확인했는지 남습니다.
3. 관리자가 **정산 완료**를 누르면 그 투어는 잠겨서 더 이상 수정할 수 없습니다.
4. 제출 후 고칠 게 생기면 **다시 열기**를 누릅니다. 정산 완료된 투어는 관리자만 다시 열 수 있습니다.

### 4-7. 요약과 엑셀 내려받기

## 7. 자주 묻는 질문과 문제 해결

**인터넷이 안 되는 곳에서도 쓸 수 있나요?**
앱을 쓰는 도중에 인터넷이 끊기면 그대로 계속 입력하면 됩니다. 입력한 내용은 휴대폰에 보관됐다가 연결되면 자동으로 전송됩니다(상단 ‘대기 N건’). 다른 직원의 변경은 연결된 뒤에 보입니다.
사막·크루즈처럼 인터넷이 약한 곳으로 가기 전에는 **와이파이가 되는 곳에서 앱을 한 번 열어 두세요.** 앱을 완전히 닫았다가 인터넷 없이 다시 열면 로그인 화면이 나올 수 있습니다. 이때는 인터넷이 되는 곳에서 다시 열면 됩니다.

**두 사람이 같은 고객을 동시에 고치면요?**
나중에 저장한 쪽이 남습니다. 한 투어의 수금은 가능하면 한 사람이 맡아 주세요.

**다른 직원이 입력한 게 안 보여요.**
상단 표시가 🟢 **실시간 연결**인지 확인하세요. 🟡나 🔴면 인터넷을 확인하고, 그래도 안 되면 앱을 완전히 닫았다가 다시 여세요.

**상품 가격이 바뀌었어요.**
관리자에게 요청하세요. 가격을 바꿔도 **이미 입력된 주문은 입력 당시 가격 그대로** 남습니다.

**상품 목록에 없는 옵션을 팔았어요.**
관리자에게 상품 추가를 요청하세요. 급하면 우선 수금 탭에서 그 고객을 고르고 금액과 메모(옵션 이름)를 남겨 두세요. 상품이 추가되면 주문서에 표시하면 됩니다.

**고객을 잘못 넣었어요 / 명단을 두 번 붙여넣었어요.**
잘못 들어간 고객 이름을 눌러 **삭제**하세요. 수금 기록이 있는 고객은 수금 기록을 먼저 지워야 삭제됩니다.

**정산 완료된 투어를 고쳐야 해요.**
관리자에게 **다시 열기**를 요청하세요.

**투어를 잘못 만들었어요.**
아직 주문하기 전이면 투어 화면 위쪽 연필(✎) 옆 **휴지통** 버튼으로 직접 지울 수 있습니다. 이미 주문한 투어는 관리자에게 BDY 번호를 알려 주세요.

**엑셀 버튼을 눌렀는데 아무 일도 안 일어나요.**
인터넷 연결을 확인하세요. 아이폰은 ‘파일’ 앱의 다운로드 폴더에 저장됩니다.

**‘저장 실패’라는 빨간 알림이 떴어요.**
권한이 없는 작업(예: 완료된 투어 수정)을 했거나 서버에서 거절된 경우입니다. 화면은 서버 기록으로 다시 맞춰집니다. 같은 알림이 계속 뜨면 화면을 캡처해서 관리자에게 보내 주세요.

**화면이 이상하거나 새 기능이 안 보여요.**
앱을 완전히 닫았다가 다시 여세요. 그래도 그대로면 관리자에게 알려주세요. (상단이 🔴 대기 N건이면 0이 된 뒤에 하세요.)
