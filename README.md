# Badaya Field 사용 설명서 (직원용)

BadayaTravel 현장 업무용 앱입니다. 투어 고객의 옵션 주문서를 쓰고, 고객에게 받은 돈과 쓴 돈을 기록하고, 투어가 끝나면 정산까지 휴대폰 하나로 합니다. 한 사람이 입력하면 사무실과 다른 직원 화면에도 바로 반영됩니다.

- 앱 주소: **https://jihkim1210-dev.github.io/badayaTravel.github.io/**
- 관리자(사무실)용 운영 안내는 [ADMIN_GUIDE.md](ADMIN_GUIDE.md)에 따로 있습니다.

---

## 1. 처음 시작하기

### 1-1. 휴대폰에 설치하기

앱스토어에서 받는 앱이 아니라, 주소를 열어 홈 화면에 추가해서 씁니다. 한 번 추가하면 일반 앱처럼 아이콘을 눌러 전체 화면으로 열립니다.

| 휴대폰 | 방법 |
|---|---|
| 아이폰 | **Safari**로 주소 열기 → 아래쪽 공유 버튼(□↑) → **홈 화면에 추가** → 추가 |
| 안드로이드 | **Chrome**으로 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가** |

아이폰은 반드시 Safari로 열어야 홈 화면에 추가할 수 있습니다(카카오톡 안의 브라우저에서는 안 됩니다. 링크를 길게 눌러 ‘Safari로 열기’를 선택하세요).

### 1-2. 로그인

- 사무실에서 받은 **이메일과 비밀번호**로 로그인합니다. 회원가입 버튼은 없습니다. 계정이 없으면 관리자에게 요청하세요.
- 한 번 로그인하면 로그아웃하기 전까지 유지됩니다.
- 비밀번호를 잊었으면 관리자에게 말해 주세요. 앱에는 비밀번호 찾기 기능이 없습니다.

### 1-3. 화면 맨 위 상태 표시 읽기

오른쪽 위의 작은 표시는 지금 내 입력이 서버에 잘 들어가고 있는지 알려줍니다.

| 표시 | 뜻 | 할 일 |
|---|---|---|
| 🟢 **실시간 연결** | 정상. 입력하는 즉시 모든 직원 화면에 반영 | 없음 |
| 🟡 **연결 중** | 서버와 다시 연결하는 중 | 잠시 기다리기 |
| 🟡 **전송 중 N건** | 입력한 N건을 서버로 보내는 중 | 잠시 기다리기 |
| 🔴 **오프라인 · 대기 N건** | 인터넷이 끊김. 입력한 N건은 휴대폰에 보관 중 | 계속 입력해도 됩니다. 인터넷이 연결되면 자동으로 전송됩니다. **대기 건수가 0이 될 때까지 앱을 지우거나 브라우저 데이터를 삭제하지 마세요.** |
| 🟡 **체험 모드** | 서버에 연결되지 않은 연습용 상태 | 아래 2장 참고 |

## 2. 체험 모드와 운영 모드

| | 체험 모드 | 운영 모드 |
|---|---|---|
| 언제 | 서버 연결 정보가 없는 연습용 페이지 | 회사 앱 주소(위 주소) |
| 로그인 | 없음. 처음에 이름만 입력 | 회사 계정으로 로그인 |
| 데이터 저장 위치 | **지금 쓰는 휴대폰·브라우저에만** 저장 | 회사 서버(Supabase)에 저장 |
| 다른 직원과 공유 | 안 됨 (같은 기기의 다른 탭끼리만 맞춰짐) | 모든 직원 화면에 실시간 반영 |
| 처음 화면 | ‘예시’ 투어(BDY 4478, 가짜 고객 7명)가 들어 있음 | 비어 있음 |
| 권한 | 누구나 관리자 기능까지 사용 가능 | 직원 / 관리자 권한이 나뉨 |
| 용도 | 사용법 연습, 신입 교육 | 실제 업무 |

- **체험 모드에서 입력한 내용은 실제 업무 기록이 아닙니다.** 다른 사람에게 보이지 않고, 브라우저 데이터를 지우면 사라집니다.
- 체험 모드에서는 **설정 → 예시 데이터로 되돌리기**로 처음 상태로 돌릴 수 있고, **모두 지우고 빈 상태로**로 연습 기록을 전부 지울 수 있습니다.
- 회사 앱 주소로 열었는데 ‘체험 모드’가 보이면 관리자에게 알려주세요(서버 연결 설정 문제입니다).

## 3. 화면 구성

아래쪽 탭 3개가 있습니다.

- **투어**: 투어 목록과 오늘 현황
- **상품**: 지역별 옵션 상품과 가격 (보기는 모두, 수정은 관리자만)
- **설정**: 내 정보, 앱 설치 안내, 서버 연결 상태, 로그아웃

### 3-1. 투어 목록 (첫 화면)

- **오늘 수금**: 오늘 모든 투어에서 기록된 수금 합계 (통화별)
- **진행중 투어 미수금**: 진행중인 투어에서 아직 받지 못한 금액 합계
- **진행중 / 정산 제출 / 완료 / 전체**: 투어 상태별로 걸러 보기
- 투어 카드: BDY 번호, 지역, 기간 코드, 출발일, 가이드, 인원, 판매액, 수금액, 수금률 막대, 미수금
- **최근 기록**: 모든 투어에서 방금 입력된 수금·지출 8건. 누르면 해당 투어로 이동

## 4. 업무 순서

### 4-1. 투어 만들기

투어 목록에서 **+ 새 투어**를 누르고 입력합니다.

| 칸 | 입력 형식 | 예 |
|---|---|---|
| BDY 번호 | **숫자만**. 같은 번호의 투어는 하나만 만들 수 있음 | `4229` |
| 지역 | 두바이(AED 기준, 팁만 USD) / 이집트(EUR 기준, Cruise Tips만 USD) | 이집트 |
| 투어 기간 코드 | 목록에서 고르거나 직접 입력 | `EK3N6D`, `KE4N6Dsig` |
| 출발일 | 날짜 선택 | 2026-10-05 |
| 가이드 / 인솔자 | 이름 (기본값은 내 이름) | 김가이드 |
| Tour Expense 요금 (이집트만) | €90 또는 €100 중 선택 | €100 |

- 투어 정보는 투어 화면 오른쪽 위 ✎ 버튼으로 언제든 고칠 수 있습니다.
- 이집트 투어에서 Tour Expense 요금을 나중에 바꾸면, 이미 입력한 고객들의 Tour Expense 금액도 함께 바뀝니다.

### 4-2. 고객 넣기

투어 화면 → **주문서** 탭.

**한 명씩 넣기: + 고객 추가**

| 칸 | 형식 | 예 |
|---|---|---|
| 그룹 | 숫자. 비워 두면 0(그룹 없음) | `1` |
| 이름 (한글) | 자유 | 홍길동 |
| 이름 (영문, 여권) | 여권 표기. 자동으로 대문자로 바뀜 | `HONG/GILDONG` |
| 호칭 | Mr / Ms | Mr |
| 특이사항 | 자유. 고객 카드에 노란 글씨로 보임 | 홈쇼핑 고객, 보상 사유 |

한글·영문 이름 중 하나는 꼭 입력해야 합니다. **추가 후 계속**을 누르면 창이 닫히지 않고 다음 고객을 바로 입력할 수 있습니다(그룹은 유지).

**여러 명 한 번에 넣기: 명단 붙여넣기**

엑셀이나 구글 시트에서 아래 순서의 4개 열을 선택해 복사한 뒤, 입력칸에 붙여넣고 **추가**를 누릅니다.

| A열 | B열 | C열 | D열 |
|---|---|---|---|
| 그룹 번호 | 한글 이름 | 영문 이름 | 호칭 (Mr/Ms) |

```
1	홍길동	HONG/GILDONG	Mr
	김영희	KIM/YOUNGHEE	Ms
2	이철수	LEE/CHULSOO	Mr
```

- 한 줄에 한 명입니다. 엑셀에서 복사하면 칸 사이가 자동으로 탭으로 들어갑니다. 직접 입력할 때는 쉼표(`,`)로 나눠도 됩니다.
- **그룹 칸이 비어 있으면 바로 윗줄의 그룹을 따릅니다.** 엑셀에서 그룹 번호를 첫 사람에게만 적고 셀 병합한 경우에도 그대로 복사하면 됩니다.
- 그룹 열 없이 `한글, 영문, 호칭` 3개 열만 붙여넣어도 됩니다(첫 칸이 숫자나 빈칸이 아니면 그룹 열이 없는 것으로 봅니다). 이때는 모두 그룹 1이 됩니다.
- 호칭 칸은 `Mr`, `Ms`만 알아듣습니다(대소문자 상관없음). 그 외에는 비워 둡니다.
- 제목 줄(‘그룹, 이름…’)은 복사하지 마세요. 제목 줄도 고객으로 들어갑니다. 잘못 들어간 사람은 이름을 눌러 **삭제**하면 됩니다.
- 붙여넣기 전에 한 번 더 확인하세요. 같은 명단을 두 번 붙여넣으면 두 번 들어갑니다.

**고객 수정·삭제**: 고객 이름을 누르면 수정 창이 열립니다. **삭제**는 주문까지 같이 지웁니다. 수금 기록이 있는 고객은 삭제되지 않으니, 수금 탭에서 그 고객의 수금 기록을 먼저 지우세요.

### 4-3. 옵션 주문 받기

주문서 탭 위쪽 **누르면** 칸에서 먼저 상태를 고르고, 고객 카드의 상품을 누릅니다.

| 상태 | 뜻 | 받을 돈에 포함 | 엑셀 CC 시트 표기 |
|---|---|---|---|
| **현금** | 현장에서 고객에게 돈을 받을 옵션 | **포함** | 1 |
| **선결제** | 한국에서 미리 결제한 옵션 | 제외 | 0 |
| **홈쇼핑** | 홈쇼핑 상품에 포함된 옵션 | 제외 | 0 |
| **보상** | 회사가 보상으로 제공하는 옵션 | 제외 | 0 |

- 한 번 누르면 고른 상태로 표시되고, **같은 상태에서 한 번 더 누르면 취소**됩니다.
- 이미 ‘현금’인 상품을 ‘선결제’ 상태에서 누르면 선결제로 바뀝니다.
- 상품 버튼 색: 초록 = 현금, 청록 = 선결제, 보라 = 홈쇼핑, 금색 = 보상.
- **선택한 상품만**을 켜면 고객 카드에 고른 상품만 보여서 화면이 짧아집니다. 상품을 더 고를 때는 **+ 상품 선택**을 누르세요.
- **카드 / 표** 버튼으로 엑셀처럼 생긴 표 보기로 바꿀 수 있습니다(태블릿·PC에서 편합니다). 표에서 ● = 현금, P = 선결제, H = 홈쇼핑, C = 보상입니다.
- 화면 아래 검은 막대는 이 투어의 **현금 판매 합계**입니다.
- 결합상품(예: 피라미드 내부 탐험 + 문명박물관)은 요약의 ‘총 옵션 수’에서 2개로 계산됩니다.

### 4-4. 돈 받기 (수금)

고객이 돈을 내면 **바로** 기록합니다.

- 주문서 탭 고객 카드의 주황색 **미수 $120 · 수금** 버튼, 또는 **수금** 탭의 **+ 수금 기록**을 누릅니다.
- 고객 카드에서 누르면 그 고객의 남은 금액이 자동으로 채워져 있습니다. 전액을 받았으면 **수금 저장**만 누르면 됩니다.

| 칸 | 형식 |
|---|---|
| 고객 | 고객 선택. 특정 고객 몫이 아닌 돈은 ‘공통’ |
| 통화 | EUR / USD / KRW / AED / EGP |
| 금액 | 숫자만 (쉼표·기호 없이). 소수점 둘째 자리까지 |
| 방법 | 현금 / 카드 / 계좌이체 |
| 메모 | 자유 (예: 나머지는 내일) |

- 한 고객이 두 통화로 내야 하면(예: 이집트 Tour Expense €100 + Cruise Tips $15, 두바이 옵션 AED + 팁 USD) **통화별로 따로** 두 번 기록합니다.
- 일부만 받았으면 받은 만큼만 기록하세요. 남은 금액은 계속 ‘미수’로 표시됩니다.
- 잘못 입력한 수금은 수금 탭 목록에서 × 를 눌러 지우고 다시 입력합니다.
- 다 받은 고객 카드에는 초록색 **완납**이 표시됩니다.

**수금 탭에서 보이는 것**
- 통화별 **판매(현금) / 수금 / 남은 금액**. 남은 금액이 마이너스(빨간색)면 받을 돈보다 많이 받았다는 뜻입니다.
- **미수 고객** 목록과 바로 수금 버튼
- **수금 내역**: 언제, 누가, 어떤 방법으로 받았는지

### 4-5. 돈 쓰기 (지출)

**지출** 탭 → **+ 지출 기록**. 돈을 쓰는 즉시 기록하세요.

| 칸 | 형식 | 예 |
|---|---|---|
| 구분 | **투어 지출** 또는 **계좌이체·환전** | 투어 지출 |
| 장소 | 두바이 / 이집트 / 사무실 | 두바이 |
| 항목 | 목록에서 고르거나 직접 입력 | 팁, 커미션, 보상, 가이드 대납, 크루즈팁, 입장료, 식사, 교통, 기타 |
| 통화 · 금액 | 수금과 같은 형식 | AED 40 |
| 메모 | 자유 | 사파리 드라이버 팁 |

- 손에 있던 현금을 회사 계좌로 보냈거나 다른 통화로 환전해서 그 통화가 줄었으면 **계좌이체·환전**으로 기록합니다(정산서의 ‘계좌이체 및 교환’ 칸).
- 환전으로 **늘어난** 통화는 정산 탭의 ‘A 회사에서 받은 돈’에 더해서 적어 주세요.

### 4-6. 정산하기

투어가 끝나면 **정산** 탭에서 합니다. 기존 PROJECT SETTLEMENT 엑셀과 같은 계산입니다.

| 줄 | 뜻 | 입력 |
|---|---|---|
| **A** 회사에서 받은 돈 | 출발 때 회사에서 받아 간 현금 | 통화별로 **직접 입력** |
| **B** 판매 (현금 주문) | 주문서에서 ‘현금’으로 표시한 옵션 합계 | 자동 |
| **C** 지출·계좌이체 | 지출 탭 합계 | 자동 |
| **D** 카드·계좌이체 수금 | 고객이 카드·계좌이체로 낸 돈. 손에 있는 현금이 아니므로 뺌 | 자동 |
| **F** 있어야 할 돈 | A + B − C − D | 자동 |
| **E** 보유 현금 | 지금 실제로 가지고 있는 현금 | 아래 **보유 현금 세기**에서 권종별 장수 입력 |
| **편차** | E − F | 자동 |

- **보유 현금 세기**: 지폐 권종별로 **장수**를 적습니다(금액이 아니라 장 수). 예: 100달러 9장이면 100 칸에 `9`. 동전이나 권종에 없는 돈은 ‘동전·기타 금액’에 **금액**으로 적습니다.
- 표에 없는 통화(예: 이집트 파운드)를 갖고 있으면 **다른 통화 추가**에서 고른 뒤 세면 됩니다.
- **편차 읽는 법**: 0(초록) = 정확히 맞음, 마이너스(빨강) = 돈이 부족, 플러스(주황) = 돈이 남음. 아직 못 받은 미수금이 있으면 그만큼 마이너스로 나옵니다. 수금 탭에서 미수 고객부터 확인하세요.
- 숫자 칸은 입력하고 다른 곳을 누르는 순간 저장됩니다.
- **비고**: 편차 사유 등을 적습니다(예: 360 비는 돈, 20유로 추가 납부 필요).

**정산 제출과 확인**
1. 가이드가 확인을 마치면 **정산 제출**을 누릅니다. 투어 상태가 ‘정산 제출’로 바뀝니다.
2. 사무실에서 **재무팀 확인**, **대표 확인**을 누릅니다(관리자만). 누가 언제 확인했는지 남습니다.
3. 관리자가 **정산 완료**를 누르면 그 투어는 잠겨서 더 이상 수정할 수 없습니다.
4. 제출 후 고칠 게 생기면 **다시 열기**를 누릅니다(정산 완료된 투어는 관리자만 다시 열 수 있습니다).

### 4-7. 요약과 엑셀 내려받기

**요약** 탭에는 상품별 **신청 인원, 현금 인원, 선결제·홈쇼핑·보상 인원, 금액**과 **총 옵션 수**(결합상품 2개로 계산)가 나옵니다. 기존 CC 시트 아래쪽 합계와 같습니다.

**엑셀로 내려받기**를 누르면 파일 하나에 시트 4개가 들어 있는 엑셀이 저장됩니다. 파일 이름은 `BDY4229_EGYPT_2026-10-07.xlsx`처럼 BDY 번호, 지역, **내려받은 날짜**로 만들어집니다.

## 7. 자주 묻는 질문

**인터넷이 안 되는 곳에서도 쓸 수 있나요?**
앱을 쓰는 도중에 인터넷이 끊기면 그대로 계속 입력하면 됩니다. 입력한 내용은 휴대폰에 보관됐다가 연결되면 자동으로 전송됩니다(상단 ‘대기 N건’). 다른 직원의 변경은 연결된 뒤에 보입니다.
인터넷이 약한 곳으로 가기 전에는 **와이파이가 되는 곳에서 앱을 한 번 열어 두세요.** 앱을 완전히 닫았다가 인터넷 없이 다시 열면, 로그인 상태에 따라 로그인 화면이 나올 수 있습니다.

**두 사람이 같은 고객을 동시에 고치면요?**
나중에 저장한 쪽이 남습니다. 한 투어의 수금은 가능하면 한 사람이 맡아 주세요.

**상품 가격이 바뀌었어요.**
관리자에게 요청하세요. 가격을 바꿔도 **이미 입력된 주문은 입력 당시 가격 그대로** 남습니다.

**상품 목록에 없는 옵션을 팔았어요.**
관리자에게 상품 추가를 요청하세요. 급하면 우선 수금 탭에서 그 고객을 고르고 금액과 메모(옵션 이름)를 남겨 두세요. 상품이 추가되면 주문서에 표시하면 됩니다.

**엑셀 버튼을 눌렀는데 아무 일도 안 일어나요.**
인터넷 연결을 확인하세요. 아이폰은 ‘파일’ 앱의 다운로드 폴더에 저장됩니다.

**화면이 이상하거나 새 기능이 안 보여요.**
앱을 완전히 닫았다가 다시 여세요. 그래도 그대로면 관리자에게 알려주세요.
